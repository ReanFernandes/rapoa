# final_paper_plotting/ — Paper Figure and Table Generation

This directory contains the scripts used to generate all figures and tables in the paper. The scripts are pegged to the specific campaign IDs from the paper's experiment runs and will not work out-of-the-box for new experiments — see [Adapting for New Runs](#adapting-for-new-runs) below.

---

## Structure

```
config.py                   Shared config: campaign IDs, slugs, paths, colours, NeurIPS style
plot_heatmap.py             Main results heatmap (success rate by condition × task)
plot_opt_trajectory.py      Optimisation trajectory plots (V reward over cycles)
plot_threshold_sensitivity.py  δ threshold sensitivity sweep
plot_threshold_heatmap.py   Threshold sweep heatmap
plot_pareto.py              Pareto efficiency plots
plot_efficiency.py          Non-optimised efficiency comparison
plot_crosstask_heatmap.py   Cross-task transfer heatmap
plot_ba_attribution.py      Behaviour Analyser attribution breakdown
gen_paper_tables.py         Main results tables (LaTeX)
gen_all_results_table.py    Full results CSV
gen_condition_summary.py    Per-condition summary statistics
gen_appendix_seed_table.py  Appendix per-seed breakdown table
gen_ba_attribution_tables.py  BA attribution tables
gen_ba_constraint_table.py  BA constraint violation table
```

Generated output goes to `figures/` and `tables/`.

---

## Running

Run any script from the repository root:

```bash
python final_paper_plotting/plot_heatmap.py
python final_paper_plotting/gen_paper_tables.py
```

All scripts read from `optimization_runs/` and `logs_fresh_eval_optimised/` under the campaign IDs set in `config.py`.

## Adapting for New Runs

All hardcoded references live in `config.py`. Two sections need updating:

### 1. Campaign IDs

`CAMPAIGN_IDS` maps a logical name to the timestamped directory created by `run_pipeline.py`:

```python
CAMPAIGN_IDS: dict[str, str] = {
    "primary_20":       "primary_20_20260522_110326",   # ← paper run
    "primary_minimal":  "primary_20_minimal_20260522_115028",
    ...
}
```

Replace the values with your own campaign directory names. To list available campaigns:

```bash
python -c "from final_paper_plotting.config import list_campaigns; print('\n'.join(list_campaigns()))"
```

Or just look in `optimization_runs/babyai/{model}/` — each subdirectory is a campaign.

### 2. Slugs (if conditions changed)

`SLUGS` maps a human-readable condition name to the slug string generated by `run_pipeline.py`. If you changed experiment parameters or added new conditions, update the relevant entries:

```python
SLUGS: dict[str, str] = {
    "hsp_rich":   "spa_mean_valbag_t005_rich",   # ← generated by run_pipeline._slug()
    ...
}
```

The slug for any run can be found as the directory name under `optimization_runs/babyai/{model}/{campaign}/`.

### 3. Model name (if changed)

`MODEL_NAME` in `config.py` controls which subdirectory under `optimization_runs/babyai/` is read:

```python
MODEL_NAME = "gpt-oss-20b"   # ← change to match your model directory name
```
